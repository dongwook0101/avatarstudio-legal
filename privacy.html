개인정보처리방침

시행일: 2026년 11월 15일

아바타스튜디오(이하 “회사”)는 소속 크리에이터의 콘텐츠 판매·전달을 위해 내부 운영 도구(이하 “도구”)를 사용하며, 이 과정에서 처리하는 개인정보를 아래와 같이 안내합니다.

1. 처리하는 정보와 목적

  • 콘텐츠 구매자가 전달받기 위해 직접 알려준 구글 계정 이메일 주소: 구매한 파일에 보기 권한을 부여하기 위해 사용합니다.
  • 권한 부여 기록(대상 파일, 부여 시각): 전달 확인, 중복·오류 방지, 문의 대응을 위해 사용합니다.

2. 구글 사용자 데이터의 이용

도구는 크리에이터 본인의 구글 계정으로 승인받아 구글 드라이브 API에 접근합니다. 접근 범위는 해당 크리에이터 드라이브의 판매 파일 확인과 구매자에게 보기 권한을 부여·확인하는 일로 한정합니다. 구글 사용자 데이터를 광고, 판매, 제3자 제공, 인공지능 모델 학습에 사용하지 않습니다. 도구의 구글 API 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 보관 기간과 파기

전달 기록은 거래 확인과 분쟁 대응에 필요한 기간 동안 보관하며, 관련 법령에서 정한 보관 기간이 있으면 그에 따릅니다. 목적이 끝난 정보는 지체 없이 삭제합니다.

4. 제3자 제공과 처리 위탁

회사는 개인정보를 제3자에게 제공하지 않습니다. 파일 공유는 구글 드라이브 기능을 통해 이루어집니다.

5. 정보주체의 권리

구매자는 언제든지 부여된 권한의 해제나 전달 기록의 열람·삭제를 요청할 수 있습니다. 요청은 구매한 플랫폼의 메시지나 아래 문의처로 할 수 있습니다.
